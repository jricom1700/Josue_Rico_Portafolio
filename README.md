## Desarrollo Local

```bash
npm install
npm run dev
```

## Despliegue en Vercel

El proyecto ya cuenta con [`vercel.json`](./vercel.json) y el script `npm run build` configurado para despliegue directo en Vercel:

1. Sube esta carpeta a un repositorio en GitHub e impórtalo en [vercel.com/new](https://vercel.com/new), **o bien**
2. Ejecuta desde la terminal:
   ```bash
   npx vercel --prod
   ```
